# 受注データ整形・見積書自動作成ツール（VBA + Python）

受注データCSVを取り込み、整形したExcelブックの出力と、発注者ごとの見積書PDFの自動作成を行うツールです。VBAとPythonを連携させ、Excel上のボタン操作だけで完結する構成にしています。

## 背景・課題

受注データを人手で1件ずつExcelに転記し、見積書を都度作成する作業を自動化することを想定した検証用ツールです。以前VBAだけで作成した同様のデモツールを、Pythonでも実装し直したものです。

## できること

Excelブック「01_受注データまとめ・見積書作成ツール.xlsm」の実行ボタンを押すと、以下が自動で行われます。

1. ダイアログボックスが開き、取り込む受注データCSVを選択
2. データを整形し、CSVと同じ場所に**同名のxlsxファイル**として保存（「元データ」「振り分け」「まとめ」の3シート構成）
   - 元データ：CSVの内容をそのまま出力
   - 振り分け：個数の数だけ行を複製し、1行＝1個の単位に展開
   - まとめ：商品番号ごとに個数を集計し、合計金額も算出
3. **発注者（姓＋名）ごと**に、テンプレート（`Invoice_Template.xlsx`）へ明細を差し込み、見積書PDFとして同フォルダ内の「見積書」フォルダに保存
   - 1件の見積書に入りきらない場合（明細が12種類を超える場合）は、自動で複数ページ（複数PDF）に分割
   - 同じ商品番号なのに商品名や単価が食い違っているデータがあれば、処理後に警告メッセージで通知

## 処理の流れ

```
[Excel] 実行ボタン (VBA: RunOrderProcessor)
   │
   ├─ exeの存在チェック（無ければエラーメッセージ）
   ├─ カーソルを砂時計に、ステータスバーに「処理中です...」を表示
   ▼
WScript.Shell経由でOrderProcessor.exeを起動し、終了を待機（同期実行）
   │
   ▼
ダイアログでCSVファイルを選択
   │
   ▼
① 受注データを整形（元データ／振り分け／まとめ） → xlsxとして保存
② 発注者（姓＋名）ごとにグループ化 → Invoice_Template.xlsxへ明細を差し込み
   → Excel実機（win32com）でPDFとしてエクスポート → 「見積書」フォルダへ保存
   │
   ▼
[Excel] カーソル・ステータスバーを元に戻し、完了メッセージを表示
```

- Excel操作（ボタン設置・exeの起動と終了待ち・処理中のUI表示）は **VBA** が担当
- データ整形・PDF生成のロジック本体は **Python** が担当（`order_processor.py` → exe化）

## 使用技術

| 分類 | 使用技術 |
|---|---|
| Excel操作・実行トリガー | VBA |
| データ整形 | Python（pandas, openpyxl） |
| PDF生成 | Python + Excel実機のCOM操作（`pywin32` / `win32com.client`） |
| GUI（ファイル選択・完了通知） | tkinter |
| exe化 | PyInstaller |

> **注意：** PDF出力にはExcelの数式計算とレイアウトをそのまま利用するため、Excel実機をバックグラウンドで自動操作する方式（`win32com`）を採用しています。そのため、**実行するPCにMicrosoft Excelがインストールされている必要があります**（Excelが無い環境ではPDF出力のみ動作しません）。

## 動作イメージ

### 入力：受注データCSV

ECサイトのテスト注文データ（架空）を使用しています（`sample_data/`に格納）。主な項目は以下の通りです。

| 項目 | 内容 |
|---|---|
| 受注コード | 同じ注文でまとめて発生した明細を紐づけるキー |
| 注文日・商品名・商品番号・個数・単価 | 明細行の情報 |
| 注文者名字・名前 等 | 発注者情報（見積書の宛先グループ化に使用） |

同じ発注者が複数回・複数商品を注文しているケースにも対応し、姓名が一致する行をまとめて1件（または複数ページ）の見積書に整形します。

### 出力：見積書PDF

`Invoice_Template.xlsx` のフォーマットに沿って、宛先・件名（「◯年◯月◯日ご注文分」）・見積No・見積日・明細（摘要／数量／単価／金額）を差し込んだ見積書をPDF化します。金額列（O列）はテンプレート側の数式（`=IF(AND(数量<>"",単価<>""), 数量*単価, "")`）をそのまま活かし、Excel実機で開いて計算させた状態でPDFに変換しています。

## セットアップ

```bash
pip install -r requirements.txt
pyinstaller --onefile order_processor.py --name OrderProcessor
```

生成された `OrderProcessor.exe` を、`01_受注データまとめ・見積書作成ツール.xlsm` と `Invoice_Template.xlsx` と同じフォルダに配置してください。

## 使い方

1. `01_受注データまとめ・見積書作成ツール.xlsm` を開き、実行ボタンをクリック
2. ダイアログで受注データCSVを選択
3. 処理が完了すると、CSVと同じ場所に整形済みxlsxファイルが、同フォルダの「見積書」フォルダに発注者ごとの見積書PDFが生成される
4. 商品番号ごとに商品名・単価の不整合があった場合は、完了時に警告メッセージが表示される

## 設計上の工夫

- **Python環境が無くても動くようにexe化**：利用側にPythonのインストールやライブラリ管理を求めず、`.exe`をExcelと同じフォルダに置くだけで動作する配布形態にした
- **処理中であることが分かるUI**：VBA側で`WScript.Shell`を使いexeの終了を待ってから制御を戻す（同期実行）ようにし、待機中はカーソルを砂時計に、ステータスバーに「処理中です。しばらくお待ちください...」と表示することで、ユーザーが処理中に誤って再操作しないようにした
- **Excel操作に慣れたユーザーでも使えるよう、VBAボタンから起動する導線に**：処理の中身はPythonだが、ユーザーから見ると使い慣れたExcelマクロの操作感を維持できる
- **テンプレートの数式をそのまま活かすPDF化方式**：金額計算をPython側で再実装せず、Excel実機に計算させてからPDF化することで、テンプレート側の数式変更にも自動で追従できるようにした
- **明細が多い発注者への対応**：見積書のテンプレートに入りきらない場合（12種類超）は自動でページを分割し、手作業での調整を不要にした
- **データ不整合の検知**：同じ商品番号で商品名・単価が食い違うデータがあれば警告を出し、集計ミスに気づけるようにした
- **exe化したことでスケジュール自動実行にも対応可能**：VBA単体の場合Excelを開いた状態での実行が前提になるが、exeにしたことでタスクスケジューラ等からの無人実行にも展開しやすい（VBA版との速度比較では大きな差はないが、実行方式の柔軟性が上がった）

## VBA版との比較

以前、同じ処理をVBAのみで実装したデモツールを作成しており、その発展として「同じ要件をPython実装・exe化した場合にどう変わるか」を検証したのが本ツールです。処理速度自体はVBA版と大きくは変わりませんが、Python化によりexe配布・スケジュール実行など運用面の選択肢が広がりました。
